# 투자 관제탑 (invest-hub)

매수자리 점수 · 확신 종목 매수존 전략 · 경제 안정성 · 실시간 차트 · 하락장 전략실을 한 화면에 모은 개인용 PWA.

- **코드는 공개, 데이터는 암호화** : 빌드 결과(`data.enc.json`)는 `HUB_PASSWORD` 로 AES-256-GCM 암호화된 뒤 GitHub Pages 에 올라간다. 비밀번호 없이는 종목·보유·신호 어떤 것도 보이지 않는다. 공개 저장소라 Actions 실행 시간 무료·무제한.
- **갱신** : 미국 정규장 전후 30분 간격 + 장외 4회 (GitHub 예약 실행은 지연·누락될 수 있음). 화면은 열려 있는 동안 5분마다 새 데이터를 확인.
- **실시간** : 상단 시세 띠와 「실시간 차트」 는 TradingView 위젯(실시간). 점수·신호는 마지막 빌드 기준.
- **알림** : 매수존 접근·신호·익절 알림은 기존 `market-risk-radar/conviction-sentinel` 메일·푸시가 원본이다. 이 화면은 같은 규칙으로 재계산한 상태를 보여준다.

## 설정 (GitHub → Settings → Secrets and variables → Actions → Secrets)

| 이름 | 필수 | 내용 |
|---|---|---|
| `HUB_PASSWORD` | 필수 | 화면 잠금 비밀번호 (12자 이상 권장) |
| `GH_READ_TOKEN` | 선택 | `market-risk-radar` 저장소 **Contents: Read-only** fine-grained 토큰 → 보유 장부·MRI·실적일 자동 연동 |
| `HOLDINGS_JSON` | 선택 | 토큰 대신 보유를 직접 입력 : `[{"ticker":"GOOGL","shares":160,"avg":330,"atr0":9.15}]` |

종목 추가·삭제 : `config/universe.json` 수정 후 커밋 → 자동 재빌드.

## 점수 산식과 검증 (2026-09-28)

**매수자리 점수 v2** (0~100) = 종목 200일선 위 30 · SPY 상승추세 20 · 20일 고점 대비 눌림(ATR) 30 · 반전 캔들 10 · 12-1개월 모멘텀 10.
v1(근거 등급 가중 6요소)은 24종목 2013~2026 검증에서 점수대별 성과 차이가 없어(단조성 −0.43) 폐기. 세부 조건 36칸도 전반·후반 재현 실패(상관 −0.46).
두 기간 모두 같은 방향으로 재현된 조건 = 「시장·종목 상승추세 + 2 ATR 이상 눌림」 → 20일 SPY 대비 +0.3~0.4%p. **효과는 작다.**
신뢰도 = 같은 상태였던 과거 날의 20일 성과가 전반(2013~19)·후반(2020~) 모두 평균을 넘었는지.

**경제 안정성** = 관제실 7축 산식(침체확률·근원CPI·NFCI·10Y−3M·VIX·실업률·CAPE)을 1990년부터 월별 재현(발표 시차 반영).
점수대별 이후 12개월 S&P500 −15% 급락 확률 : 80점↑ 6% / 60~80점 30~34% / 60점↓ 14~18% (전체 20%). 수준보다 **12개월 고점 대비 −15점 이상 악화 시 37.5%** 가 더 강한 신호.

## 구조

```
build_hub.py         수집 → 계산 → 암호화 → site/
hub/buyscore.py      매수자리 점수 + 점수대·상태별 백테스트
hub/conviction.py    확신 종목 매수존 규칙 재현 + 과거 신호 통계
hub/stability.py     경제 안정성 월별 재현 + 급락·침체 백테스트
hub/data.py          yfinance · FRED · 뉴욕연준 · multpl · 관제실 payload · 비공개 장부
web/                 화면 (index.html · app.js · app.css · PWA)
```

정보 도구이며 투자 자문이 아니다.
